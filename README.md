# 迷你交通大亨

全 3D 網頁版交通運輸大亨模擬遊戲（原型）。小島上有一條環狀鐵路和 3 個車站，可以切換蒸汽火車、高鐵、路面電車三種車種。

島上住著 21 位機器人居民，每位都有自己的名字、穿著打扮（帽子、圍巾、眼鏡、衣服花色）和隨身物品（背包、氣球、雨傘、吉他等）。頭上天線的燈色代表要去的車站，灰色表示正在散步。列車會自動進站停靠並打開月台側的車門。車廂是中空的，有透明車窗、滑門、地板和座椅：機器人會走進車門、沿走道找到座位坐下，到站後起身走出車門。每送達一位乘客就依搭乘距離賺取車資。乘客下車後不會消失，而是走下月台到附近散步，之後再回到車站搭下一班車。每個火車頭都有一位穿制服的機器人列車長在駕駛。

操作面板可以用右上角的按鈕或 H 鍵收合。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm run build    # 輸出到 dist/
```

## 結構

- `src/main.js`：場景、燈光、相機與操作面板
- `src/track.js`：封閉軌道（道碴、枕木、鋼軌）與沿軌道取點
- `src/train.js`：列車編組、車種設定（容量、速度）、蒸汽
- `src/parts.js`：共用材質、輪軸、車身放樣（loft），以及開窗車身與座椅內裝（buildCabin）
- `src/steam.js`：蒸汽火車頭與客車廂
- `src/modern.js`：高鐵與路面電車
- `src/stations.js`：車站、居民行程（散步、候車、上下車）與收入
- `src/robots.js`：機器人模型、穿著、隨身物品與列車長
- `src/world.js`：小島、樹、房子、雲

技術：Three.js + Vite。
