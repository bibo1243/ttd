# 迷你交通大亨

全 3D 網頁版交通運輸大亨模擬遊戲（原型）。一開始小島上沒有鐵路，玩家用 $5,000 起始資金自己鋪環狀鐵路、蓋車站，可以切換蒸汽火車、高鐵、路面電車三種車種。

## 建造

- **鐵路**：在地上點出轉折點（對齊 0.5 格），會自動連成一圈，轉角變成圓弧彎道。預覽是綠色代表可以蓋、紅色會寫出原因（彎道太急、交叉、超出島嶼、資金不足）。點黃色起點或按「完成環線」就蓋好。每公尺 $12。
- **車站**：移到鐵路旁，滑鼠在哪一側就蓋在哪一側；需要一段 8 公尺的平直鐵路。每站 $600，最多 8 站。每蓋一站會有 6 位新居民搬來。
- **拆除**：點車站拆掉它，點鐵路拆掉整條環線和所有車站，退回一半費用。列車停靠時不能拆。
- 蓋在樹、房子、石頭上會先清除（樹 $15、房子 $150、石頭 $5）。
- **範例路線**：一鍵蓋好原型的環線和 3 個車站。
- 目前一次只能有一條環線。進度會存在瀏覽器裡，「重新開始」可以清除。

島上住著機器人居民，每位都有自己的名字、穿著打扮（帽子、圍巾、眼鏡、衣服花色）和隨身物品（背包、氣球、雨傘、吉他等）。頭上天線的燈色代表要去的車站，灰色表示正在散步。列車會自動進站停靠並打開月台側的車門。車廂是中空的，有透明車窗、滑門、地板和座椅：機器人會走進車門、沿走道找到座位坐下，到站後起身走出車門。每送達一位乘客就依搭乘距離賺取車資。乘客下車後不會消失，而是走下月台到附近散步，之後再回到車站搭下一班車。每個火車頭都有一位穿制服的機器人列車長在駕駛。

**家**：島上的房子是照機器人比例蓋的小屋，每位居民都有自己的家。屋裡有木地板、壁紙、床、沙發、餐桌椅、廚房、冰箱、書架、盆栽和掛畫，窗戶是透明玻璃、掛著窗簾，屋內有暖色的檯燈、立燈和吊燈。居民散步時會不時回家：推開前門走進去，坐在沙發或餐桌、在廚房做菜、看書架，或躺在床上睡個午覺，從窗戶就看得到。鏡頭拉近到房子旁邊時屋頂會掀開，可以直接看進屋裡。蓋鐵路經過房子一樣會拆除（$150），屋裡的居民會先走出來。

操作面板可以用右上角的按鈕或 H 鍵收合。

## 公路與車輛

- **公路**：點起點、再點下一個點鋪一段雙向兩車道的公路（每公尺 $10），可以一路點下去，從路尾接續時會自動接成平順的彎道。從其他道路的路尾或路邊開始就會接成岔路；和其他道路交叉會自動做成十字路口（有斑馬線和停止線）；穿過鐵路會自動蓋平交道，列車靠近時警示燈閃爍、柵欄放下，車子會停在柵欄前。路尾會有迴車道。人行道上每隔一段有路燈。卡片上可以切換「拆除」，點一段公路拆掉並退回一半費用。
- **公車站**：蓋在公路旁的人行道上（每站 $300），有候車亭、長椅、站牌和燈箱廣告。每蓋一站會有 3 位通勤族搬來：在附近散步、到站牌排隊（前三位坐長椅），公車到站後從前門上車找位子坐下，到目的地從中門下車並付車資（依兩站距離計算）。
- **車輛**：車輛清單可以調整路上有幾台轎車、計程車、小貨車、公車、機車、自行車。居民的車不用錢；公車一台 $1,200，會依建站順序繞行所有公車站載客。「自訂車種」可以選車款、顏色、取名字，新增到清單裡開上路。
- 每台車都有機器人司機（公車司機穿制服），轎車和計程車會載著乘客，機車騎士戴安全帽、可以載人，自行車騎士會踩踏板。車子會跟車、在路口輪流通過、讓路給路上的機器人，機車和自行車轉彎時會壓車。
- 開發用的車輛展示頁：`npm run dev` 後打開 `/garage.html`。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm run build    # 輸出到 dist/
```

網址加上 `?perf` 會在右下角顯示 FPS、draw call 和三角形數；加上 `?stress` 會在小島外圍生成一片大陸（6000 棵樹、800 棟房子、1000 顆石頭），用來測試大地圖效能。`?time=19` 可指定時間（0–24 時），`?quality=low|medium|high` 可指定畫質（預設依幀率自動調整）。

## 結構

- `src/main.js`：場景、燈光、相機與操作面板
- `src/network.js`：鐵路網（節點與彎道、分岔、號誌閉塞、尋路）
- `src/train.js`：列車編組、車種設定（容量、速度）、蒸汽
- `src/parts.js`：共用材質、輪軸、車身放樣（loft），以及開窗車身與座椅內裝（buildCabin）
- `src/steam.js`：蒸汽火車頭與客車廂
- `src/modern.js`：高鐵與路面電車
- `src/build.js`：建造工具（鋪鐵路、蓋車站、路線、買賣列車、拆除、費用、存檔）
- `src/stationStyles.js`：三種車站造型（小站、一般站、大車站）
- `src/residents.js`：居民的名字與個性
- `src/planet.js`：星球弧形地平線（頂點著色器彎曲，網址加 `?flat` 可關閉）
- `src/modules.js`：功能模組（住家、商店…）掛進遊戲的地方
- `src/stations.js`：車站、居民行程（散步、候車、上下車）與收入
- `src/robots.js`：機器人模型、穿著、隨身物品與列車長
- `src/world.js`：小島、樹、房子、雲
- `src/homes/`：可住人的房屋（house.js 外觀與家具、index.js 居民回家、開門、屋頂掀開與室內燈光）
- `src/instancing.js`：大量靜態物件的繪製（Scatter：instancing、分區視錐剔除、遠處 LOD）
- `src/batching.js`：機器人零件的批次繪製（BatchedPart：每個零件照常放進場景階層，實際由共用的 BatchedMesh 畫出）
- `src/render.js`：光影與畫質（Look：天空、太陽、時間變化、暖光燈具、環境光遮蔽與泛光後製、自動畫質分級）
- `src/perf.js`：效能工具
- `src/roads/`：公路模組（`index.js` 建造工具與車輛清單、`net.js` 路網與車道、`mesh.js` 路面外觀、`traffic.js` 車流與公車、`props.js` 候車亭與平交道）
- `src/vehicles/`：道路車輛模型（`cars.js` 轎車／計程車／小貨車、`bus.js` 公車、`bikes.js` 機車／自行車、`crew.js` 司機與乘客、`kit.js` 共用材質與合併繪製）

技術：Three.js + Vite。
